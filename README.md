# The Tacticon Game Room

Homepage for **https://drtacticon.github.io/** with illustrated links to:

- [Breakfast in Tokyo](https://drtacticon.github.io/breakfast-in-tokyo/)
- [Pandora: Survive the Wreck](https://drtacticon.github.io/pandora-survive-the-wreck/)

Static HTML and CSS; no build step or server-side dependencies. GitHub Pages serves the `main` branch from the repository root. Both game cards are accessible links, with responsive artwork, keyboard focus styling, and reduced-motion support.

## Artwork

- Tokyo cover: existing monster artwork from the Breakfast in Tokyo project.
- Pandora cover: original artwork generated for this homepage with the built-in image generation tool. The user approved the cover before integration. Web exports preserve the approved scene.

The full-resolution Pandora original and its generation prompt are preserved in the author's local `game-room-art` workspace folder.
